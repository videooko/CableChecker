# Документація проєкту CableChecker (Universal Cable Tester)

Ця папка містить актуальну технічну, архітектурну та експлуатаційну документацію універсального тестера кабелів на базі **ESP8266 (WeMos D1 Mini)**, розширювача портів **MCP23017** та дисплея **OLED SSD1306 (128×64)**.

---

## Зміст документації

1. **[Апаратна архітектура та схемотехніка](01_Hardware_Architecture.md)**
   - Аналіз принципової схеми (`REV: 1.0`) та розведення друкованої плати.
   - Карта пінів ESP8266 (`U3`) та розширювача MCP23017 (`U6`).
   - Роз'єми тестування `RJ3.1` / `RJ3.2` та зовнішні підтяжки `10 кОм`.
   - Схеми підключення 1 кнопки, 2 кнопок або енкодера `EC11` через колодку `U9`.
   - Концепція зовнішніх перехідників `RJ45 -> Кабель` та правила електробезпеки.

2. **[Архітектура прошивки та алгоритми](02_Firmware_Architecture.md)**
   - Модульна структура ПЗ (`include/` та `src/`).
   - 4-фазний алгоритм безпечного псевдо-Open-Drain сканування.
   - Класифікація дефектів (`OPEN`, `CROSS`, `SHORT A-B`, `SHORT Local`, `EXTRA`).
   - Опис профілів кабелів та карта пам'яті EEPROM.
   - Оптимізація шини I2C (`dirty flag`) та повністю неблокуючий цикл (`FSM`).

3. **[Інструкція користувача](03_User_Manual.md)**
   - Опис екранів інтерфейсу (`Matrix View` та `Pin Mapping View`).
   - Розшифровка символів на екрані та кодів помилок.
   - Керування пристроєм (1 кнопка / 2 кнопки / енкодер).
   - Як зберегти власний кабель/перехідник як еталон (`CUSTOM REF`).

4. **[Журнал змін та ітерацій (Changelog)](04_Changelog.md)**
   - Історія аудитів, виправлених критичних помилок та оновлень прошивки.
   - Статистика використання ресурсів (RAM / Flash) по кожній версії.
   - План наступних доробок (Roadmap).
