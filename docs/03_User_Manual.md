# 3. Інструкція користувача та розшифровка індикації (v3.1 — Енкодер)

## 3.1. Керування енкодером (Проєкт → Кабель → Тестування)

Завдяки обробці енкодера на апаратних перериваннях (`IRAM_ATTR`), обертання ручки миттєво реагує на кожен клац без пропусків навіть під час активного сканування кабелю:

| Екран пристрою | Поворот ВПРАВО (`CW`) | Поворот ВЛІВО (`CCW`) | Короткий клік (`Click`) | Утримання (`Hold > 0.85 с`) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Екран тестування (`Matrix View`)** | Наступний кабель поточного проєкту | Попередній кабель поточного проєкту | Перехід у детальну карту контактів (`Pin Details`) | Вхід у головне **Меню Проєктів** |
| **2. Екран тестування (`Pin Details`)** | Наступна сторінка `[P1/2]` ↔ `[P2/2]` | Попередня сторінка `[P1/2]` ↔ `[P2/2]` | Повернення на **Графічну матрицю (`Matrix`)** | Вхід у головне **Меню Проєктів** |
| **3. Меню Проєктів (`SELECT PROJECT`)** | Курсор `>` вниз по списку | Курсор `>` вгору по списку | **OK (Вибрати)** проєкт або дію | **Назад / Вихід** на екран тестування |
| **4. Меню Кабелів (`PRJ: ...`)** | Курсор `>` вниз по списку кабелів | Курсор `>` вгору по списку кабелів | **OK (Активувати)** обраний кабель | **Назад** до списку проєктів |
| **5. Екран Wi-Fi (`192.168.4.1`)** | — | — | Вимкнути Wi-Fi та вийти в тестер | Вимкнути Wi-Fi та вийти в тестер |

### Пункти головного Меню Проєктів (`SELECT PROJECT`):
1. **`1..N. Назва Проєкту (Кількість кабелів)`** — Клік відкриває список кабелів обраного проєкту.
2. **`[Save Active Cab]`** — Миттєвий запис підключеного зараз зразкового кабелю у поточний слот.
3. **`[Wi-Fi Web Setup]`** — Запуск вбудованого Wi-Fi Web-конфігуратора (`http://192.168.4.1`).
4. **`< Exit to Tester`** — Повернення на екран тестування.

## 3.2. Робочі екрани на OLED (128×64)

### Екран 1: Графічна матриця (`VIEW_MATRIX`)

```text
+-----------------------------------+
| Sens 4->6            [PASS  OK]   | <- Назва кабелю та вердикт
|-----------------------------------|
| A:  1   2   3   4                 | <- Активні контакти Роз'єму А (1..pinsA)
|     |   |   |   |                 | <- Статус кожної лінії відносно схеми
| B:  1   3   4   6                 | <- На який пін Сторони Б прийшов сигнал
|-----------------------------------|
| Project A [4->6P]                 | <- Назва проєкту / Формула роз'ємів / Помилки
+-----------------------------------+
```

#### Розшифровка символів середнього рядка (Статус лінії):
- **`|`** — Лінія справна і точно відповідає схемі кабелю (`PIN_STATUS_OK`).
- **`x`** (мала літера) — Обрив лінії або однієї з гілок розгалуженого джгута (`PIN_STATUS_OPEN`).
- **`X`** (велика літера) — Помилка комутації: переплутані жили (`CROSS`), коротке замикання (`SHORT`) або зайвий контакт поза схемою (`EXTRA`).
- **`.`** (крапка) — Очікуваний контакт схеми, коли кабель ще не вставлений (`NO CABLE`).

#### Розшифровка символів рядка `B:` (Куди прийшов сигнал):
- **`1`..`8`** — Сигнал зі сторони А прийшов на один контакт сторони Б з відповідним номером.
- **`+`** — Штатне розгалуження `1-на-N` (наприклад, спільний `GND` з `A1` на `B1` та `B4`), яке **відповідає схемі кабелю (`OK`)**.
- **`J`** — Штатна локальна перемичка на стороні А (`A-A`), яка **відповідає схемі кабелю (`OK`)**.
- **`*`** — Аварійне КЗ одразу на декілька контактів сторони Б (`SHORT!`).
- **`S`** — Аварійне локальне КЗ між контактами сторони А (`SHORT A-A`).
- **`-`** — На стороні Б сигнал відсутній (розімкнено).

## 3.3. Робота з вбудованим Wi-Fi Web-конфігуратором (`192.168.4.1`)

1. Утримуйте кнопку (`Hold > 1.1 с`) для входу в меню проєктів.
2. Короткими кліками наведіть курсор на **`[Wi-Fi Web Setup]`** та затисніть кнопку (`Hold`).
3. З'явиться екран **`WI-FI WEB CONFIG AP`**.
4. Підключіться зі смартфона або ноутбука до відкритої Wi-Fi мережі **`CableChecker-Setup`**.
5. Відкрийте у браузері адресу **`http://192.168.4.1`**.
6. У Web-інтерфейсі ви можете:
   - Створювати та перейменовувати проєкти (до 8 проєктів).
   - Додавати кабелі в кожен проєкт (до 8 кабелів на проєкт), задавати кількість пінів **`pinsA (1..8)`** та **`pinsB (1..8)`**.
   - Формувати будь-яку схему розпайки: клікати по клітинках матриці `A ↔ B`, додавати розгалуження `1-на-N` або локальні перемички `A-A` / `B-B`.
   - Натиснути кнопку **«Зчитати з кабелю в тестері»** — пристрій просканує вставлений зараз у роз'єми `RJ3.1`/`RJ3.2` фізичний кабель і автоматично заповнить таблицю розпайки!
   - Натиснути **«Зберегти все у тестер»** для запису в `LittleFS`.
   - Натиснути **«Експорт JSON»** або **«Імпорт JSON»** для збереження резервної копії всіх проєктів у файл на телефоні/ПК.
7. Для виходу з режиму Wi-Fi натисніть кнопку на тестері — радіомодуль Wi-Fi повністю вимкнеться.
